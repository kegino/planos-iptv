# Planos IPTV — Comparativo Oficial e Assinaturas 4K

Plataforma oficial do **Planos IPTV** (`planosiptv.online`), o portal de streaming IPTV líder em custo-benefício no Brasil com mais de 35.000 canais ao vivo, filmes de cinema e esportes sem travamento.

## 🚀 Tecnologias

- **Framework**: TanStack Start + Vite + React 19
- **Estilização**: Tailwind CSS v4 + Radix UI + Lucide React
- **SEO & Otimização**: Schema.org estruturado (Product, FAQPage, HowTo, BlogPosting, OfferCatalog), OpenGraph completo, Canonical Tags dinâmicas, Sitemap XML e RSS Feed nativo.
- **Identidade Visual**: Backdrop cinematográfico *Dune: Part Two* otimizado em WebP ultraleve (~17 KB), paleta Golden Desert Onyx com botões Solar Amber de altíssimo contraste e legibilidade impecável.

## 💻 Executando localmente

```sh
git clone https://github.com/kegino/planos-iptv.git
cd planos-iptv
pnpm install
pnpm dev
```

## 📦 Build para Produção

```sh
pnpm build
```
